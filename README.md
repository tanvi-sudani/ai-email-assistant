
**AI Email Assistant**

AI Email Assistant is a modern web application that helps users generate professional, customized emails instantly using OpenAI's GPT API.

-------------------------
**Features**
-------------------------
- Generate emails based on:
  - Topic
  - Tone (Professional, Friendly, Formal)
  - Template type
  - Prompting techniques:
    - Role Prompting
    - Zero Shot Prompting
    - Few Shot Prompting
- Adjustable email length
- Professional UI/UX
- Dark mode support
- Copy generated emails
- Download emails as TXT
- Responsive design for desktop and mobile


-------------------------
**Technologies Used**
-------------------------
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- OpenAI API (gpt-4o-mini)

-------------------------
**Installation & Setup**
-------------------------
1. Clone the Repository
    git clone https://github.com/tanvi-sudani/AI-Email-Assistant.git
   
3. Open Project Folder
    cd AI-Email-Assistant
   
5. Add Your OpenAI API Key
    Inside script.js:  const API_KEY = "YOUR_OPENAI_API_KEY";

4. Run the Project
    Simply open:  index.html in your browser.
